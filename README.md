# drawings and code

> I realized the world was missing yet another developer blog, so I decided to write it: [drawings-and-code.eu](https://drawings-and-code.eu/)

## About me

Full stack development lead with experience across client-side, server-side and infrastructure technologies, mainly in JavaScript/TypeScript (Node.js, Nest.js, React, Svelte), working on small to large applications and pipelines backed by Postgres, Elasticsearch, Redis, Docker, Google Cloud and AWS, deployed with Terraform and GitHub Actions.

I build production backend services in Rust, including axum APIs for authentication and access control, as well as CLI developer tooling, and have experience with Ruby (Rails and Sinatra) and Python.

AI-assisted development is part of my daily workflow: I work with Claude Code, integrate with the OpenAI API, and build MCP servers and agent-oriented tooling.

## Work

Currently the Platform Lead at [DigestAID](https://digestaid.health/), owning the engineering platform, identity layer and developer tooling behind a suite of AI medical products regulated under EU MDR and FDA, in digestive healthcare, gynecology and pulmonology.

Previously at [BENlabs](https://www.benlabs.com/), leading a team responsible for the internal and external facing applications, defining the technical requirements and supporting the implementation of new features across the frontend, backend and AWS deploy.

## Personal projects

My personal projects live on **[Codeberg](https://codeberg.org/drawings_and_code)** — that's the place to look for code, tools and experiments. This GitHub account is mostly for work and contributions.

In my spare time I'm building [Flowmoney](https://flowmoney.eu), a personal expense manager focused on anticipating the next expenses and account balance, as opposed to the usual reports on what we spent: I'm trying to know what I can spend before I spend it, not where I overspent (before it's too late).
